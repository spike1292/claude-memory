# `vault-mcp`: a read-only MCP server for a claude.ai custom connector

**Date:** 2026-10-13 · **Issue:** #111

## Decision

`scripts/vault-mcp.mjs` serves `list_projects`, `search` and `get_note` over Streamable HTTP,
`POST /mcp`, JSON responses only. It speaks MCP `2026-07-28` and nothing older. It binds
`127.0.0.1` unless `--host` says otherwise; a reverse proxy in front does TLS.

## Why each rule

- **Bearer token, checked here, before the body is read.** The connector dialog sends static
  request headers, so `Authorization: Bearer <token>` is the auth it can do. The check lives in
  this repo so a test proves it, not in the proxy config. The proxy's IP allow rule is a second
  lock, not the first.
- **Token from a file, never from env.** `--token-file`, else
  `$CREDENTIALS_DIRECTORY/vault-mcp-token` (systemd `LoadCredentialEncrypted=`). A token in env
  leaks into child processes and traces. Under 32 bytes, the server does not start.
- **`Origin` present means 403.** The only client is Anthropic's connector backend, a server. A
  browser is never a legitimate caller, so there is no allow-list to keep.
- **`2026-07-28` only.** Owner decision. A legacy `initialize` gets `-32022` with
  `supported: ["2026-07-28"]`, which tells a dual-era client to retry as modern. Risk accepted:
  if the connector client is legacy-only it cannot connect, and each request's logged
  `MCP-Protocol-Version` and `clientInfo` show it on the first attempt.
- **`project` is required and must be an indexed slug.** A connector has no working directory,
  so the project cannot be inferred. `isIndexedSlug()` takes the slug from the index filenames,
  so a client string never becomes a path; `loadIndex()` and `--serve` use the same guard.
- **`search` falls back to BM25 without recall's gates.** The `--serve` socket answers when it is
  up; otherwise the server spawns it and ranks the slug's CARD rows with the same `bm25()` call
  as recall's `keywordArm()`. Recall's score floor exists to keep weak notes out of a prompt; a
  search tool returns a ranking and the caller judges it. Every reply names the `arm`.
- **`get_note` reads only `vaultSources()` folders, by real path.** The same list the indexer
  reads, so what search can return is what can be read, and a symlink out is refused.
- **No write path.** Writes are a later phase with their own review.

## Not done

OAuth, rate limits, CORS, SSE, sessions, cross-project search, and the deployment (systemd unit,
proxy, cold-start check), which lives in `agentic-os`.
